## 🚗 1. 차선 검출(Lane Detection) 관점 분석

### 1.1 차선 유형 및 가시성

| 특징 | 상세 설명 | 난이도 |
|------|---------|--------|
| **차선 종류** | 흰색 점선(차선 구분), 흰색 실선(횡단보도), 노란색 이중 실선(중앙선) 혼재 | ⚠️ 중 |
| **횡단보도** | 거의 모든 교차로에 넓은 횡단보도(Zebra crossing) 존재 — 차선과 혼동 가능 | 🔴 상 |
| **노면 상태** | 아스팔트 도로, 일부 구간에 "FIRE LANE" 등 도로 텍스트 마킹 존재 | ⚠️ 중 |
| **차선 마모/오염** | 도심 도로 특성상 차선이 부분적으로 마모되어 흐릿한 구간 다수 | 🔴 상 |

### 1.2 차선 검출의 주요 도전 과제

1. **🌙 야간 환경 (Low Light)**
   - 전 구간이 야간(21시)이므로 전체적으로 어두운 노출
   - 가로등과 건물 조명에 의한 불균일한 조명 분포
   - 그림자와 반사광이 차선 검출 알고리즘을 교란

2. **💡 극심한 조명 변화 (Extreme Light Variation)**
   - 타임스퀘어 구간: 대형 LED 전광판에서 나오는 강렬한 색상 조명
   - 일반 도심 구간: 가로등 중심의 비교적 균일한 조명
   - 한 영상 안에서 **매우 밝은 구간 ↔ 매우 어두운 구간**이 교차

3. **🔍 광각 렌즈 왜곡 (Wide-angle Distortion)**
   - 블랙박스 광각 렌즈로 인한 **배럴 왜곡(Barrel distortion)** 확인
   - 이미지 가장자리에서 직선이 곡선으로 왜곡
   - 차선 검출 전 **카메라 캘리브레이션 & 왜곡 보정** 필수

4. **🚸 복잡한 도로 구조**
   - 다차선 도로(4~6차선)에 회전 차선 포함
   - 빈번한 교차로로 인해 차선이 끊기는 구간 다수
   - 횡단보도 줄무늬가 차선과 유사한 에지 생성

5. **🚕 차선 가림(Occlusion)**
   - 대형 버스(M7, M20), 택시, SUV 등이 차선을 완전히 가림
   - 특히 밀집 교통 구간에서 전방 차선의 소실점 추정이 어려움

### 1.3 차선 검출 알고리즘별 적합도

| 알고리즘 | 적합도 | 이유 |
|---------|--------|------|
| **Canny + Hough Transform** | ❌ 낮음 | 야간 노이즈 + 광고판 에지에 크게 영향 받음 |
| **Color Space Filtering (HSV/HLS)** | ⚠️ 보통 | 흰/노란 차선 분리 가능하나 네온 광고판이 간섭 |
| **Sliding Window + Polynomial Fit** | ⚠️ 보통 | ROI 설정 필수, 교차로 구간에서 실패 가능 |
| **딥러닝 기반 (LaneNet, UFLD 등)** | ✅ 높음 | 야간+도심 복합 환경에 가장 강건 |

### 1.4 전처리 권장 사항

- **왜곡 보정**: 체커보드 캘리브레이션으로 광각 렌즈 왜곡 제거
- **적응형 히스토그램 평활화 (CLAHE)**: 야간 대비 개선
- **ROI 마스킹**: 하단 50~60% 영역만 사용 (상단 건물/광고판 제거)
- **OSD 제거**: 상단 타임스탬프 + 하단 센서 데이터 영역 마스킹
- **감마 보정**: 밝기 불균일 보정

## 🎯 2. 객체 검출(Object Detection) 관점 분석

### 2.1 검출 가능한 객체 유형

| 객체 카테고리 | 출현 빈도 | 특징 |
|-------------|----------|------|
| **🚗 승용차 (Car)** | ★★★★★ | 세단, SUV 등 다양한 차종. 택시(노란색)가 특히 빈번 |
| **🚌 버스 (Bus)** | ★★★★☆ | NYC 시내버스(MTA, 흰색), 관광버스 다수 출현 |
| **🚖 택시 (Taxi)** | ★★★★★ | 노란색 뉴욕 택시가 거의 모든 프레임에 존재 |
| **🚶 보행자 (Person)** | ★★★★★ | 타임스퀘어 구간에서 수십 명 이상 밀집 |
| **🚲 자전거 (Bicycle)** | ★★☆☆☆ | 간헐적으로 등장 |
| **🚦 신호등 (Traffic Light)** | ★★★★☆ | 교차로마다 존재, 녹색/빨간색 신호 식별 가능 |
| **🪧 표지판/광고판** | ★★★★★ | 대형 LED 전광판, 도로 표지판, 상점 간판 |
| **🏗️ 공사 구조물** | ★★☆☆☆ | 일부 구간에 비계(scaffolding) 존재 |

### 2.2 객체 검출의 주요 도전 과제

1. **🌑 야간 조건에서의 객체 인식**
   - 어두운 색상의 차량(검정, 남색)은 배경과 구분 어려움
   - 보행자의 실루엣이 건물 그림자와 혼합
   - 차량 헤드라이트/테일라이트의 글레어(Glare) 효과

2. **👥 밀집 객체 (Crowded Scene)**
   - 타임스퀘어 구간: 한 프레임에 **30+ 보행자, 10+ 차량** 동시 등장
   - 객체 간 **심한 겹침(Occlusion)** — NMS 임계값 조정 필요
   - 소형 객체(원거리 보행자)가 수 픽셀 크기로 축소

3. **📐 다양한 객체 스케일**
   - 근거리 버스: 프레임의 30~40% 차지
   - 원거리 차량: 수십 픽셀 크기
   - 멀티스케일 검출 능력 필수 (FPN, SSD 등)

4. **🎨 강한 배경 잡음**
   - 대형 LED 광고판의 이미지가 객체(자동차, 사람)를 포함 → 허위 검출 가능
   - 건물 유리 반사에 비친 차량/사람도 오검출 위험
   - 차량 후드에 반사된 광고판 반사광

5. **📷 OSD 오버레이**
   - 상단: 날짜/시간 텍스트 → 텍스트 검출기에 간섭 가능
   - 하단: 속도/가속도 센서 데이터 + 재생 바 UI → 마스킹 필요
   - 하단 영역에 차량 후드 반사 → 가짜 객체로 오인 가능

6. **🔄 모션 블러 (Motion Blur)**
   - 주행 중 촬영으로 인해 빠르게 지나가는 객체에 모션 블러 발생
   - 교차로 통과 시 좌우 차량의 블러가 특히 심함

### 2.3 객체 검출 모델별 적합도

| 모델 | 적합도 | 이유 |
|------|--------|------|
| **SSD MobileNet V2** | ⚠️ 보통 | 경량이라 실시간 가능하나 야간 소형 객체에 약함 (워크스페이스에 이미 존재) |
| **YOLOv5/v8** | ✅ 높음 | 멀티스케일 검출 + 야간 환경 강건성 우수 |
| **Faster R-CNN** | ✅ 높음 | 정확도 높으나 실시간 처리 어려움 |
| **DETR (Transformer 기반)** | ✅ 높음 | 밀집 환경에서 우수, 다만 연산량 많음 |

### 2.4 전처리/후처리 권장 사항

- **OSD 영역 마스킹**: 상단 30px, 하단 30px 영역 제거
- **CLAHE 대비 향상**: 어두운 객체의 가시성 개선
- **NMS 임계값 조정**: 밀집 장면에서 IoU 0.3~0.4로 낮춤
- **Confidence 임계값**: 야간 환경이므로 0.3 이하도 허용 고려
- **객체 추적 병행**: DeepSORT 등으로 프레임 간 ID 유지

## 💡 4. 핵심 특징 요약

### 차선 검출 핵심 특징
1. ✅ 흰색 점선, 실선, 노란색 이중 실선이 혼재
2. ✅ 횡단보도 줄무늬가 차선과 유사한 에지를 생성 (오검출 원인)
3. ⚠️ 광각 렌즈 **배럴 왜곡**이 심하여 보정 필수
4. ⚠️ 야간 + 불균일 조명으로 기존 색상 기반 검출 한계
5. ⚠️ 도로 텍스트 마킹("FIRE LANE" 등)이 에지 검출에 간섭
6. 🔴 타임스퀘어 구간은 **광고판 반사 + 차선 마모 + 교차로 복잡도**로 인해 차선 검출 극히 어려움

### 객체 검출 핵심 특징
1. ✅ 다양한 클래스(차/버스/택시/보행자/신호등)가 동시에 출현
2. ✅ NYC 택시의 특유 노란색은 색상 기반 사전 필터링에 활용 가능
3. ⚠️ 한 프레임에 **수십 개 객체**가 밀집 → 고성능 NMS 필요
4. ⚠️ 소형 객체(원거리 보행자/차량)와 대형 객체(근거리 버스)의 **스케일 격차** 매우 큼
5. ⚠️ LED 광고판 속 이미지가 **실제 객체로 오검출** 될 위험
6. 🔴 야간 조건에서 어두운 차량/보행자의 검출률 저하 예상
7. 🔴 차량 후드 반사와 하단 OSD가 노이즈원
